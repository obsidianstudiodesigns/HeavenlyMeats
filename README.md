# Heavenly Meats · Touwsrivier

Website for Heavenly Meats, 41 Logan Street, Touwsrivier. Affordable, quality meat, fresh and frozen.

Static site with no build step:

- `index.html`: page markup
- `css/style.css`: styles
- `js/braai.js`: real-time Three.js braai scene (procedural boerewors, coals, flames, embers)
- `js/main.js`: smooth scroll, intro, scroll-driven camera, 3D product reel
- `js/cuts.js`: interactive beef, lamb and pork cut charts

Run locally with any static server, for example `python -m http.server` in this folder.
